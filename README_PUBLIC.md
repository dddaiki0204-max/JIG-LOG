# JIG LOG × 海上保安庁「海しる」連携版

釣行・釣果・ジグ・タックルを記録し、海上保安庁「海しるAPI」の潮流推算を釣行/ヒット時刻に紐付けるための構成です。

## 重要
海しるAPI v3は2026年8月27日にベータ版が開始され、2026年10月から正式版が段階提供予定です。v3はArcGIS FeatureServiceベースです。

現時点で公開ポータルにはv3の「ArcGIS FeatureService_ベータ版」が掲載されていますが、潮流推算の具体的なサービスID・レイヤーURLはポータルのOASで確認する必要があります。誤ったURLを推測して組み込まないため、`MSIL_TIDE_QUERY_URL`を環境変数で指定する設計にしています。

## 海しるAPIキー
APIキーはブラウザへ保存しません。サーバーの環境変数 `MSIL_API_KEY` に設定してください。

開発時は海上保安庁公式ポータルに掲載されている試用サブスクリプションキーを利用できます。試用キーは予告なく停止・変更される場合があります。

## 起動

```bash
npm install
```

Windows PowerShell:

```powershell
$env:MSIL_API_KEY="ここにAPIキー"
$env:MSIL_TIDE_QUERY_URL="ここに海しるv3潮流推算のFeatureServer/Layer/query URL"
npm start
```

ブラウザ:
`http://localhost:3000`

## 自動入力の流れ
1. 釣行日・潮流エリアを入力
2. 「潮流を自動取得」
3. サーバーが海しるAPI v3へ問い合わせ
4. 流向・流速などをJIG LOGへ保存
5. 釣果登録でヒット時刻を入れると、同じ釣行の潮流データを取得

## 注意
海しるの潮流推算は推算値です。航行判断には使用せず、JIG LOGでは釣果分析用の参考データとして扱ってください。
